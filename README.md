Unusual Activity Watchdog

Problem Statement

Unusual or suspicious activities can be difficult to identify when activity data is not monitored effectively. This can delay the detection of potential security risks and make it harder to respond in time.

Solution

Unusual Activity Watchdog is a web-based project designed to help monitor activity and identify potentially suspicious patterns. It provides a user-friendly interface to present activity-related information, making unusual behavior easier to recognize and investigate.

Tech Stack

React – Building the user interface

TypeScript – Writing structured and type-safe code

Vite – Development server and build tool

HTML and CSS – Structuring and styling the interface
